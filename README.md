# flcl42

I publish compact developer tools and protocol experiments, mostly around Ethereum, AI-assisted workflows, GitHub, and Windows/.NET utilities.

## Pinned Large Repos

- [Nethermind](https://github.com/NethermindEth/nethermind) - Ethereum execution client for node operators.
- [dotnet-libp2p](https://github.com/NethermindEth/dotnet-libp2p) - libp2p implementation for .NET.

## Ethereum / Protocols

- [rlp](https://github.com/flcl42/rlp) - error-tolerant RLP parser and colored hex inspector.
- [cortex-ssz](https://github.com/flcl42/cortex-ssz) - ETH2 Simple Serialize implementation for .NET.
- [EIP-4844 work](https://github.com/flcl42?tab=repositories&q=4844) - configs, interop, devnets, genesis files, and alternate OS testing.
- [dotnet-zk](https://github.com/flcl42/dotnet-zk) and [zkbf](https://github.com/flcl42/zkbf) - ZK-related .NET experiments.

## AI / Automation

- [coder](https://github.com/flcl42/coder) - detachable Codex wrapper for long-running terminal sessions.
- [kanban-fs](https://github.com/flcl42/kanban-fs) - VS Code Kanban board backed by folders and Markdown files, with optional agent runner.
- [gptcheck](https://github.com/flcl42/gptcheck) - AI/checking experiments.

## Git / GitHub / Workflow

- [pr](https://github.com/flcl42/pr) - compact PR dashboard, opener, and notification cleaner.
- [gitfear](https://github.com/flcl42/gitfear) - Git workflow experiments.

## Other Tools

- [bonk](https://github.com/flcl42/bonk) - .NET 10 Native AOT Windows notification sound executable.
- [bzdonk](https://github.com/flcl42/bzdonk) - earlier notification sound executable.
- [powder](https://github.com/flcl42/powder) - VS Code password encryption helper.
- [snoopest](https://github.com/flcl42/snoopest) - HTTP/WebSocket proxy logger.
- [remote-console](https://github.com/flcl42/remote-console) - remote console and file management app.
- [Cubism-pics](https://github.com/flcl42/Cubism-pics) - HTML5 drawing game.
